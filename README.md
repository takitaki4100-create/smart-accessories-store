# Smart Accessories — متجر إلكتروني قابل للتشغيل

## المتطلبات
- Node.js 20 أو أحدث
- npm

## التشغيل محليًا
1. فك ضغط المشروع.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ `npm install`.
4. انسخ `.env.example` إلى `.env` وغيّر `SESSION_SECRET` وبيانات دخول المدير.
5. نفّذ `npm start`.
6. افتح `http://localhost:3000`.

لوحة الإدارة: `http://localhost:3000/admin.html` ثم سجّل الدخول ببيانات `.env`.
عند أول تشغيل ينشئ الخادم قاعدة SQLite داخل مجلد `data/` ويضيف منتجات تجريبية.

## النشر
ارفع المشروع إلى خدمة تدعم Node.js وتخزينًا دائمًا للملفات (مثل VPS أو Render مع Persistent Disk). عيّن متغيرات البيئة من لوحة الاستضافة. اربط القرص الدائم بمجلد المشروع أو عدّل `DB_PATH` حسب بيئة الاستضافة. لا تستخدم تخزينًا مؤقتًا للقرص لأن قاعدة البيانات والصور ستضيع عند إعادة النشر.

## ما الذي يعمل؟
- كتالوج المنتجات والأقسام عبر API وقاعدة SQLite.
- لوحة مدير محمية بجلسة دخول: إضافة/تعديل/حذف المنتجات والأقسام، ورفع صور من الجهاز أو وضع رابط صورة.
- تفاوض السعر بخطوة 50 دج، مع حد أدنى يفرضه الخادم عند إنشاء الطلب.
- تسعير الكميات والجملة لكل منتج: حد الجملة، مقدار انخفاض سعر الوحدة، والسعر الأدنى.
- سلة مشتريات، نموذج طلب داخل الموقع، حفظ الطلب في قاعدة البيانات.
- عرض صفحة نجاح ورقم الطلب.
- إدارة الطلبات وتغيير حالتها والبحث فيها.
- روابط التواصل قابلة للتعديل من لوحة الإدارة.

## ملاحظات مهمة قبل الإطلاق
- غيّر كلمة مرور المدير والمفتاح السري قبل النشر.
- فعّل HTTPS من منصة الاستضافة.
- أضف سياسة الخصوصية وشروط البيع ومعلومات التوصيل الفعلية.
- هذه نسخة أساس عملية وليست خدمة دفع إلكتروني؛ الدفع عند الاستلام هو الخيار الافتراضي.
- صور الفئات والمنتجات المرفقة مقتطفات من الصورة المرجعية لتقريب الهوية البصرية، ويمكنك استبدالها بصور منتجاتك الحقيقية من لوحة الإدارة.
